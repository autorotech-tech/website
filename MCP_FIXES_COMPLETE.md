## Если понадобится brave-search позже

1. Получите API ключ: https://brave.com/search/api/
2. Добавьте в `~/.cursor/mcp.json`:
```json
"brave-search": {
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-brave-search"],
  "env": {
    "BRAVE_API_KEY": "ваш_ключ_здесь"
  }
}
```
