# Решение проблемы логина в Rescue Mode через VNC

## 🔍 Важная информация:

### SSH настройки НЕ влияют на VNC:
- ✅ SSH использует ключи (id_ed25519_autoro)
- ✅ VNC использует **отдельный пароль** (обычно предоставляется хостингом)
- ✅ Это **разные системы аутентификации**

### VNC пароль:
- Обычно предоставляется хостинг-провайдером (Contabo в вашем случае)
- Может быть в панели управления хостингом
- Может быть отправлен на email при активации rescue mode
- Может отличаться от root пароля сервера

## 🔧 Решения проблемы "incorrect credentials":

### 1. Проверить пароль VNC в панели управления:
- Зайти в панель управления Contabo
- Найти раздел "Rescue Mode" или "VNC Access"
- Проверить/сбросить пароль VNC
- Обычно это отдельный пароль от root

### 2. Попробовать стандартные пароли:
- Пароль, который вы использовали при создании сервера
- Пароль, который был в email от Contabo при активации rescue mode
- Пароль root (если он был установлен)

### 3. Сбросить пароль VNC через панель управления:
- В панели Contabo найти опцию "Reset VNC Password"
- Или "Regenerate Rescue Mode Password"
- Новый пароль будет отправлен на email

### 4. Альтернативные способы доступа:

#### A. Через SSH (если доступен):
```bash
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229
```

#### B. Через панель управления Contabo:
- Может быть встроенный терминал в веб-интерфейсе
- Или консоль через браузер

#### C. Через IPMI/KVM (если доступно):
- Некоторые хостинг-провайдеры предоставляют IPMI доступ
- Это альтернатива VNC

## 📋 Пошаговая инструкция:

### Шаг 1: Проверить панель управления Contabo
1. Зайти на https://contabo.com
2. Войти в аккаунт
3. Найти сервер `vmi2607864`
4. Перейти в раздел "Rescue Mode" или "VNC"
5. Проверить/сбросить пароль VNC

### Шаг 2: Если пароль не найден
1. Связаться с поддержкой Contabo
2. Указать номер сервера: `vmi2607864`
3. Попросить сбросить пароль VNC для rescue mode

### Шаг 3: После входа в rescue mode
1. Проверить доступность дисков: `lsblk` или `fdisk -l`
2. Примонтировать основной диск (если нужно)
3. Выполнить необходимые операции

## ⚠️ Важно:

- **VNC пароль ≠ SSH ключи** - это разные системы
- **VNC пароль ≠ root пароль** - может отличаться
- **Rescue mode** обычно требует отдельного пароля
- Пароль обычно **временный** и меняется при каждой активации rescue mode

## 🔐 Если нужно сбросить root пароль:

После входа в rescue mode:
```bash
# Примонтировать основной диск
mount /dev/sda1 /mnt  # или другой раздел

# Chroot в систему
chroot /mnt

# Сбросить пароль root
passwd root

# Выйти из chroot
exit
umount /mnt

# Перезагрузить сервер в обычном режиме
```
