# Решение проблемы блокировки для России

## Проблема

`swoop.autoro.tech` не открывается с IP России - GCore CDN не справляется с обходом блокировки.

## Решения

### Вариант 1: Использовать Cloudflare Tunnel (РЕКОМЕНДУЕТСЯ)

Cloudflare Tunnel может обойти блокировки лучше, чем CDN.

1. Установить cloudflared на сервере
2. Создать tunnel для swoop.autoro.tech
3. Настроить маршрутизацию через tunnel

### Вариант 2: Использовать другой CDN

**Bunny CDN:**
- Менее известен, может не блокироваться
- Дешевле ($1/TB)
- Простая настройка

**AWS CloudFront:**
- Очень надежный
- Может не блокироваться в некоторых регионах

### Вариант 3: Использовать VPN/tunnel сервис

Настроить VPN или туннель для обхода блокировки.

### Вариант 4: Настроить дополнительные правила в GCore CDN

Проверить, есть ли в GCore CDN настройки для обхода блокировок:
- WAAP правила
- IP whitelisting
- Geo-blocking bypass

---

## Текущая архитектура

```
Browser (Russia) → GCore CDN → nginx-proxy → swoop.autoro.tech
```

Проблема: GCore CDN блокируется на уровне провайдера/Роскомнадзора.

---

## Рекомендация

Для обхода блокировки лучше использовать Cloudflare Tunnel, так как он создает зашифрованное соединение, которое сложнее заблокировать.
