# Babylon Fish (Вавилонская Рыбка) — Синхронный Переводчик Звонков

**Babylon Fish** — это высокоскоростной синхронный переводчик реального времени (RU ↔ EN) на базе WebRTC платформы **LiveKit** и архитектурных концепций **Google Intensive**. Проект интегрирует продвинутые средства безопасности (фильтрация PII и детекция Prompt Injection) в неблокирующем потоковом режиме, предлагая динамический выбор синтеза речи и бесшовные шлюзы для популярных приложений.

---

## 1. Архитектура и Особенности

```
  [ Входящий Аудиопоток ] (Микрофон / SIP / RTMP / Виртуальный Кабель)
             │
             ▼
     [ LiveKit Room ]
             │
             ▼
 [ Deepgram Nova-3 STT ] (Транскрипция реплик в текст)
             │
             ▼
  [ SecurityFilterNode ] (Проверка на PII / Prompt Injection)
             │
             ├───────────────────────────────────────┐
             │ (Асинхронный аудит)                   │ (Мгновенное продолжение)
             ▼                                       ▼
 [ capture_moderation_queue ]             [ TranslationNode ] (Gemini 2.5 Flash)
 (Запись в БД для модератора)                        │
                                                     ▼
                                        [ SpeechSynthesisNode ]
                                        (Google Journey / ElevenLabs Flash)
                                                     │
                                                     ▼
                                         [ Исходящий Аудиопоток ]
```

### Ключевые преимущества:
1. **Неблокирующий Потоковый Режим (Non-blocking HITL)**:
   При обнаружении конфиденциальных данных (PII) или инъекций промптов система асинхронно логирует инцидент в БД Supabase для проверки модератором, но **не останавливает** голосовой поток. Очищенный текст моментально направляется на перевод и синтез, убирая любые задержки в диалоге.
2. **Динамический Выбор TTS (Speech Synthesis)**:
   Пользователи и администраторы могут в реальном времени переключать основной TTS-движок в админке:
   * **Google Cloud TTS (Journey/Neural2)**: Сверхбыстрый синтез голосами нового поколения (задержка < 200 мс).
   * **ElevenLabs Flash v2.5**: Премиальное качество звучания с естественной интонацией (задержка 350-450 мс).
   * **Auto-Fallback**: При сбое выбранного движка система мгновенно переключается на запасной без обрыва звонка.
3. **Шлюзы Интеграции популярного ПО**:
   Готовые скрипты и руководства для сопряжения переводчика с **Zoom, Microsoft Teams, Skype, Telegram, WhatsApp** и телефонными сетями (**SIP VoIP**).

## 2. Быстрый Старт (Локальный Запуск)

### Шаг 1: Настройка Окружения

Перейдите в директорию бэкенда переводчика и разверните виртуальное окружение:

```bash
cd /Users/vlad_x/Desktop/n8n/autoro.tech/ai-translator-backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

*Примечание: Для стабильного сопряжения с LiveKit рекомендуется использовать Python 3.11 или 3.12.*

### Шаг 2: Настройка Конфигурации (`.env`)

Скопируйте шаблон конфигурации и заполните ключи:

```bash
cp .env.example .env
```

Заполните переменные:
* `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` — учетные данные сервера LiveKit.
* `DEEPGRAM_API_KEY` — API-ключ для транскрипции Nova-3.
* `GOOGLE_API_KEY` — API-ключ Gemini Flash.
* `ELEVENLABS_API_KEY` — API-ключ ElevenLabs.
* `BOOKMARKS_PG*` — реквизиты базы данных Supabase (для синхронизации настроек и очереди модерации).

## 3. Инструкция по Тестированию

Вы можете запустить и протестировать переводчик в режиме симуляции звонка с помощью встроенной песочницы:

### Шаг 1: Запуск Агента Переводчика

Запустите службу агента LiveKit в режиме разработки:

```bash
python3 agent_adk_translator.py dev
```

Агент подключится к серверу LiveKit и будет ожидать вызова диспетчера для перевода.

### Шаг 2: Создание Тестовой Сессии

Сгенерируйте комнату на сервере LiveKit и получите JWT-токены доступа для тестовых участников (один говорит по-русски, второй — по-английски):

```bash
python3 create_livekit_session.py --room babylon-test-room --out livekit_test_session.json
```

Эта команда создаст файл `livekit_test_session.json` с токенами для участников `caller_ru` (атрибут `language: ru`) и `caller_en` (атрибут `language: en`).

### Шаг 3: Диагностика и Эмуляция Подключения

Запустите скрипт автоматической диагностики подключения и подписки на медиапотоки:

```bash
bash run_livekit_connect_debug.sh livekit_test_session.json
```

Диагностические отчеты будут сохранены в файл `.cursor/debug-b36587.log` в корне проекта.

## 4. Интеграция Звонков (Popular Call Apps)

Для подключения Babylon Fish к внешним каналам связи используйте универсальную утилиту `call_integration.py`:

### А. SIP / VoIP Телефония
Настройка прямого подключения телефонной линии к переводчику (требуются данные провайдера SIP, например Telnyx или Twilio):

```bash
python3 call_integration.py sip --room babylon-phone-room --number +1234567890 --carrier telnyx
```
Это зарегистрирует SIP-транк и создаст входящий маршрут. Любой звонок на номер `+1234567890` будет автоматически перенаправляться в комнату LiveKit с подключенным переводчиком.

### Б. RTMP Ingress (OBS / Zoom / Teams)
Если вы хотите транслировать поток из конференции Zoom или MS Teams в LiveKit:

```bash
python3 call_integration.py ingress --room babylon-meeting-room --name zoom-ingress
```
Команда выведет **Stream URL** и **Stream Key**. Направьте поток из Zoom/Teams (через OBS или аналогичное ПО вещания) на эти реквизиты.

### В. Виртуальный Аудиокабель (Telegram / WhatsApp / Discord)
Для локального перевода звонков из приложений на вашем компьютере:
1. Запустите руководство по настройке:
   ```bash
   python3 call_integration.py guide
   ```
2. Установите виртуальный кабель (BlackHole на macOS или VB-Cable на Windows).
3. В настройках звука приложения (например, Telegram -> Настройки -> Аудио):
   * Установите **Speaker (Динамик)** в значение **Virtual Cable**.
   * Установите **Microphone (Микрофон)** в значение **Virtual Cable**.
4. Запустите перенаправление аудиовыхода в LiveKit. Агент Babylon Fish будет слушать входящий звук и озвучивать перевод прямо в ваш виртуальный микрофон.

## 5. Панель Администратора (Admin UI)

Администрирование переводчика встроено в раздел **Keept Admin (Infrastructure & Call Settings)**:
1. **Переключение TTS**: На вкладке настроек вы увидите блок **Speech Synthesis**. Здесь представлены карточки **Google Cloud TTS** и **ElevenLabs Flash**. Клик по карточке мгновенно перезаписывает параметр `adk_translator_tts_engine` в таблице `public.service_settings`.
2. **Панель интеграций**: Отображает текущие статусы шлюзов и позволяет управлять SIP-конфигурацией и ключами RTMP Ingress прямо из браузера.
3. **Bot Connectors**: Позволяет в один клик подключать и отключать бот-аккаунты для совещаний в **Zoom, MS Teams, Telegram** и **WhatsApp**.

## 6. Как расшарить проект для Google Antigravity

Для передачи наработок по Babylon Fish агенту Antigravity настроен специальный скрипт зеркалирования в репозиторий `AuthRAG`:

1. Убедитесь, что репозиторий `AuthRAG` склонирован по адресу `~/AuthRAG` или находится на одном уровне с папкой `website`.
2. Запустите синхронизацию из корня директории `website`:
   ```bash
   npm run keept:sync-authrag:apply
   ```
   Этот скрипт выполнит:
   * Очистку и копирование исходного кода фронтенда `website`.
   * Синхронизацию файлов бэкенда синхронного переводчика `ai-translator-backend/` (включая обновленный `agent_adk_translator.py`, `call_integration.py` и документацию) в папку `AuthRAG/ai-translator-backend/`.
   * Выполнит автоматический коммит и пуш изменений в ветку `bookmarks-bro` репозитория `AuthRAG`.
3. Скопируйте и отправьте в новую сессию Antigravity следующий контекстный промпт:

> **Промпт для инициализации Antigravity:**
> ```
> Ты работаешь в зеркале Keept: github.com/autorotech-tech/AuthRAG, branch bookmarks-bro.
> Проект синхронного перевода звонков называется "Babylon Fish" (ai-translator-backend/).
> 
> Настройки перевода и модерации лежат в:
> - ai-translator-backend/agent_adk_translator.py (ADK-агент, потоковый неблокирующий режим с асинхронным занесением в Supabase moderation queue).
> - website/src/keeptAdmin/SettingsPanel.tsx (Админка с выбором Google TTS / ElevenLabs и шлюзами SIP/RTMP/Virtual Cable).
> - ai-translator-backend/call_integration.py (Скрипт интеграции со звонками популярных приложений).
> 
> Пожалуйста, используй эту кодовую базу для дальнейшей доработки и выполнения оценочных тестов (make playground / make grade).
> ```
