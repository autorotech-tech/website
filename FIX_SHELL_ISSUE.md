# Исправление проблемы с shell

## Проблема:
Ошибка `parse error near 'cursor_snap_ENV_VARS'` при выполнении команд через `run_terminal_cmd`.

## Решение:

Эта ошибка связана с настройками zsh в Cursor IDE, а не с реальными проблемами shell. 

### Вариант 1: Использовать простые команды без heredoc

Вместо сложных heredoc использовать простые команды:

```bash
# Простая команда
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229 "docker ps | grep blog"

# Или через скрипт на сервере
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229 "bash -s" < script.sh
```

### Вариант 2: Создавать скрипты локально и копировать

```bash
# Создать скрипт
cat > test.sh << 'SCRIPT'
#!/bin/bash
docker ps | grep blog
SCRIPT

# Скопировать на сервер
scp -i ~/.ssh/id_ed25519_autoro test.sh vladx@46.250.228.229:/tmp/

# Выполнить
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229 "bash /tmp/test.sh"
```

### Вариант 3: Использовать простые команды напрямую

Для диагностики использовать простые команды без сложных конструкций.

## Рабочее решение:

Создавать скрипты и выполнять их напрямую, либо использовать простые команды по одной.
