## 🚀 Шаг 2: Обновление Next.js и React (В ПРОЦЕССЕ)

### Текущие версии
- Next.js: 14.2.14
- React: 18.3.1
- React-DOM: 18.3.1

### Целевые версии
- Next.js: 15.x (latest)
- React: 19.x (latest)
- React-DOM: 19.x (latest)

### План обновления

1. **Обновить package.json**
2. **Проверить breaking changes**
3. **Исправить несовместимости**
4. **Протестировать все страницы**

### Известные breaking changes в Next.js 15

1. **Кэширование fetch по умолчанию**
   - Раньше: fetch кэшировался по умолчанию
   - Теперь: fetch по умолчанию динамический (no-cache)
   - Решение: Явно указать `cache: 'force-cache'` для статических данных

2. **API Routes**
   - Проверить все `/app/api/**/route.ts` файлы
   - Убедиться, что используются правильные типы

3. **Metadata API**
   - Проверить `generateMetadata` функции
   - Убедиться, что используются правильные типы

## 📦 Шаг 3: Добавление Shadcn UI

### Команды
```bash
cd blog-autoro
npx shadcn@latest init
npx shadcn@latest add card button badge separator avatar
```

### Компоненты для установки
- `card` - для карточек постов
- `button` - для кнопок
- `badge` - для тегов и статусов
- `separator` - для разделителей
- `avatar` - для аватаров авторов

## 📝 Шаг 4: Тестирование

После обновления проверить:
- ✅ Главная страница блога (`/blog`)
- ✅ Страница поста (`/blog/[slug]`)
- ✅ API routes (`/api/admin/posts`)
- ✅ Сборка проекта (`npm run build`)
- ✅ Production режим (`npm run start`)

## ⚠️ Риски и меры предосторожности

1. **Backup перед обновлением**
   - Создать git commit
   - Сохранить текущий package.json

2. **Постепенное обновление**
   - Сначала Next.js
   - Потом React
   - Тестирование на каждом шаге

3. **Откат при проблемах**
   - Вернуться к предыдущим версиям
