# Проверка: расширен ли диск провайдером?

## 🔍 Анализ ситуации:

Из вашего `lsblk`:
- `sda` - **75G** (общий размер диска)
- `sda1` - 1M
- `sda2` - 2G
- `sda3` - 73G
- **Итого использовано:** ~75G

## ❓ Вопрос: Докупили ли вы место?

Если вы докупили, например, **25G**, то:
- Общий размер диска должен быть **100G** (75G + 25G)
- Но в `lsblk` видно только **75G**

## ✅ Проверка: реальный размер диска

Выполните в rescue mode:

```bash
# 1. Проверить реальный размер диска
fdisk -l /dev/sda | grep "Disk /dev/sda"

# 2. Или более детально
fdisk -l /dev/sda

# 3. Или через parted
parted /dev/sda print
```

## 📊 Интерпретация результатов:

### Сценарий A: Диск НЕ расширен

```
Disk /dev/sda: 75 GiB, 80530636800 bytes
```

**Вывод:** Провайдер **НЕ расширил** диск. Нужно:
1. Обратиться в поддержку Contabo
2. Указать что вы докупили место, но оно не отображается
3. Попросить расширить диск

### Сценарий B: Диск расширен, но раздел не создан

```
Disk /dev/sda: 100 GiB, 107374182400 bytes  <-- БОЛЬШЕ 75G!
...
Device     Start       End   Sectors  Size Type
/dev/sda1   2048      4095      2048    1M BIOS boot
/dev/sda2   4096   4196351   4192256    2G Linux filesystem
/dev/sda3  4196352 157286399 153090048   73G Linux filesystem
                                    ^^^^  <-- КОНЕЦ sda3
157286400 2147483647 1990197248  25G  <-- СВОБОДНОЕ МЕСТО!
```

**Вывод:** Диск расширен, но **раздел не создан**. Нужно:
1. Создать новый раздел на свободном месте
2. Отформатировать его
3. Примонтировать

### Сценарий C: Диск расширен, раздел создан, но не отформатирован

```
Disk /dev/sda: 100 GiB, 107374182400 bytes
...
Device     Start       End   Sectors  Size Type
/dev/sda1   2048      4095      2048    1M BIOS boot
/dev/sda2   4096   4196351   4192256    2G Linux filesystem
/dev/sda3  4196352 157286399 153090048   73G Linux filesystem
/dev/sda4  157286400 2097151999 1939865600  25G Linux filesystem  <-- ЕСТЬ!
```

Но в `lsblk -f` нет FSTYPE для sda4:

```
sda4  25G  -  -  <-- БЕЗ FSTYPE (не отформатирован)
```

**Вывод:** Раздел создан, но **не отформатирован**. Нужно:
1. Отформатировать: `mkfs.ext4 /dev/sda4`
2. Примонтировать
3. Добавить в fstab

## 🎯 Что делать дальше:

### Если диск НЕ расширен (Сценарий A):

1. **Обратиться в поддержку Contabo:**
   - Указать номер сервера
   - Указать что докупили место (сколько GB)
   - Попросить расширить диск
   - Обычно это делается через панель управления или тикет

2. **Проверить в панели управления Contabo:**
   - Зайти в панель управления
   - Посмотреть размер диска в настройках сервера
   - Если там тоже 75G - значит место не добавлено

### Если диск расширен (Сценарий B или C):

Следуйте инструкциям из `SAFE_PARTITION_MOUNT.md`:
1. Создать раздел (если его нет)
2. Отформатировать
3. Примонтировать
4. Добавить в fstab

## 📝 Команды для быстрой проверки:

```bash
# В rescue mode (без chroot)
fdisk -l /dev/sda

# Или
parted /dev/sda print

# Посмотреть свободное место
parted /dev/sda print free
```

## ⚠️ ВАЖНО:

- Если `fdisk -l` показывает **75G** - провайдер не расширил диск
- Если показывает **больше 75G** - диск расширен, нужно создать/настроить раздел
- **НЕ создавайте разделы** если диск не расширен - это может повредить данные!
