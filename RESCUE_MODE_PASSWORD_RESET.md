# Сброс пароля root в Rescue Mode

## 🔍 Текущая ситуация:

- ✅ Подключились к VNC в rescue mode
- ❌ Не можете залогиниться под root (пароли не подходят)
- ❓ Можно ли использовать SSH для сброса пароля?

## 🔧 Решения:

### Вариант 1: Попробовать залогиниться в rescue mode под другим пользователем

В rescue mode попробуйте:
- Логин: `rescue` (пароль: пустой или `rescue`)
- Логин: `admin` (пароль: пустой)
- Логин: `debian` (пароль: пустой)

После входа вы сможете работать с дисками.

### Вариант 2: Использовать SSH (если доступен)

#### A. Попробовать SSH как root:
```bash
ssh -i ~/.ssh/id_ed25519_autoro root@46.250.228.229
```

**Но:** Если `PermitRootLogin` настроен как `prohibit-password` или `no`, это не сработает.

#### B. Использовать SSH как vladx и sudo:
```bash
# 1. Залогиниться как vladx
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229

# 2. Установить пароль root через sudo
echo 'vladx:iddqdidkfa' | sudo -S passwd root
# Или интерактивно:
sudo passwd root
# Ввести sudo пароль: iddqdidkfa
# Затем ввести новый root пароль дважды
```

### Вариант 3: Сбросить пароль через rescue mode (без логина)

Если в rescue mode вы видите командную строку (даже без логина), можно:

1. **Найти основной диск:**
   ```bash
   lsblk
   # Вы увидите: sda1 (1M), sda2 (2G), sda3 (73G)
   # sda3 - это ОСНОВНОЙ раздел с вашей системой
   ```

2. **Примонтировать основной раздел:**
   ```bash
   # Примонтировать sda3 (73GB - основной раздел)
   mount /dev/sda3 /mnt
   
   # Если sda2 это boot раздел (проверить: blkid /dev/sda2):
   mkdir -p /mnt/boot
   mount /dev/sda2 /mnt/boot
   ```

3. **Chroot в систему:**
   ```bash
   chroot /mnt /bin/bash
   ```

4. **Сбросить пароль root:**
   ```bash
   passwd root
   # Ввести новый пароль дважды
   ```

5. **Выйти и перезагрузить:**
   ```bash
   exit
   umount /mnt
   reboot
   ```

### Вариант 4: Если rescue mode требует логина

Если в rescue mode обязательно нужен логин, попробуйте:

1. **Логин: `rescue`** (пароль: пустой или `rescue`)
2. **Логин: `admin`** (пароль: пустой)
3. **Логин: `debian`** (пароль: пустой)

После входа выполните процедуру сброса пароля выше.

## 📋 Пошаговая инструкция через SSH (если доступен):

### Шаг 1: Проверить SSH доступ
```bash
# Попробовать как root
ssh -i ~/.ssh/id_ed25519_autoro root@46.250.228.229

# Если не работает, попробовать как vladx
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229
```

### Шаг 2: Если доступен vladx через SSH
```bash
# Залогиниться
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229

# Установить пароль root
sudo passwd root
# Ввести sudo пароль: iddqdidkfa
# Ввести новый root пароль: [ваш новый пароль]
# Подтвердить пароль: [ваш новый пароль]
```

### Шаг 3: Проверить новый пароль
```bash
# Выйти из SSH
exit

# Попробовать залогиниться через VNC с новым паролем
```

## ⚠️ Важно:

1. **SSH доступ как root** может быть отключен в `/etc/ssh/sshd_config`:
   - `PermitRootLogin no` - запрещен
   - `PermitRootLogin prohibit-password` - только ключи
   - `PermitRootLogin yes` - разрешен

2. **В rescue mode** обычно можно работать без полного логина, если есть доступ к командной строке

3. **После сброса пароля** перезагрузите сервер в обычном режиме

## 🎯 Рекомендуемый порядок действий:

1. ✅ **Попробовать SSH как vladx** (скорее всего сработает)
2. ✅ **Использовать sudo для сброса пароля root**
3. ✅ **Проверить новый пароль через VNC**
4. ⚠️ Если SSH недоступен - использовать rescue mode процедуру
