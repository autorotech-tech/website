## Рекомендации

1. **Регулярная очистка Build Cache:**
   ```bash
   docker builder prune -f
   ```

2. **Мониторинг использования диска:**
   ```bash
   df -h /
   docker system df
   ```

3. **Автоматическая очистка (crontab):**
   ```bash
   # Раз в неделю
   0 2 * * 0 docker builder prune -f
   ```

4. **Ограничение размера логов Docker** в `/etc/docker/daemon.json`:
   ```json
   {
     "log-driver": "json-file",
     "log-opts": {
       "max-size": "10m",
       "max-file": "3"
     }
   }
   ```
