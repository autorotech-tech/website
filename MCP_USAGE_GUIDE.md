# 🤖 Руководство по использованию MCP серверов

## 📋 Активные MCP серверы

Следующие MCP серверы подключены и готовы к использованию:

### 1. **nextjs-docs** (@nextjs-docs)
**Назначение:** Документация и помощь по Next.js

**Использование:**
```
@nextjs-docs Как использовать Server Actions в Next.js 15?
@nextjs-docs Покажи пример App Router с динамическими маршрутами
@nextjs-docs Как работает кэширование в Next.js 15?
```

**Полезно для:**
- Изучение Next.js API
- Поиск примеров кода
- Решение проблем с Next.js

---

### 2. **tailwindcss** (@tailwindcss)
**Назначение:** Помощь с Tailwind CSS

**Использование:**
```
@tailwindcss Покажи пример градиентного фона
@tailwindcss Как создать responsive grid?
@tailwindcss Покажи пример card компонента с тенью
```

**Полезно для:**
- Создание стилей
- Поиск правильных классов Tailwind
- Оптимизация CSS

---

### 3. **filesystem** (@filesystem)
**Назначение:** Работа с файловой системой проекта

**Использование:**
```
@filesystem Покажи структуру components/ui
@filesystem Читай файл app/blog/page.tsx
@filesystem Найди все файлы с использованием Button компонента
```

**Полезно для:**
- Навигация по проекту
- Поиск файлов
- Анализ структуры кода

---

**Полезно для:**

---

### 5. **context7** (@context7)

## 💡 Советы по использованию

1. **Комбинируйте серверы:**
   - Используйте несколько MCP серверов в одном запросе
   - Например: `@nextjs-docs @tailwindcss создай компонент карточки поста`

2. **Будьте конкретны:**
   - Четко формулируйте запросы
   - Указывайте версии (Next.js 15, React 19)
   - Приводите примеры, если нужно

3. **Используйте контекст:**
   - MCP серверы понимают контекст проекта
   - Они знают о структуре файлов
   - Используют актуальную документацию

---

## 🔍 Проверка статуса MCP серверов

В Cursor IDE:
1. Откройте **Settings** → **Features** → **MCP**
2. Все серверы должны быть активны (зеленый статус)
3. Если сервер не активен - перезапустите Cursor IDE
