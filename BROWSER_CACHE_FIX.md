# Исправление проблемы с кешем браузера

## Проблема

После исправления настроек GCore CDN:
- ✅ curl запросы работают правильно (401 без редиректа)
- ❌ Браузер все еще показывает 301 редирект из кеша
- ❌ Ошибка: `301 Moved Permanently (from disk cache)`

## Решение

### Шаг 1: Очистить кеш браузера

**Chrome/Edge:**
1. Откройте DevTools (F12)
2. Кликните правой кнопкой на кнопку обновления страницы
3. Выберите **"Очистить кеш и жесткое обновление"** (Empty Cache and Hard Reload)

ИЛИ:

1. Нажмите **Cmd+Shift+R** (Mac) или **Ctrl+Shift+R** (Windows) - жесткое обновление
2. Если не помогло:
   - DevTools → Network → включите **"Disable cache"**
   - Обновите страницу

**Safari:**
1. Разработка → Очистить кеши
2. Cmd+Option+R для жесткого обновления

### Шаг 2: Проверить настройки кеша в GCore CDN

В GCore CDN убедитесь, что для `/api/*` кеширование отключено:

1. Проверьте правило **"Bypass API Cache"** для `/api/*`
2. Убедитесь, что **"Enable CDN caching"** выключен для API путей

---

## Альтернативное решение: Использовать другой домен для API

Если проблемы с кешем продолжаются, можно:

1. **Использовать прямой доступ к origin** (обходя GCore CDN для API):
   - API: `https://autoro.tech/api/blog/admin/*` (прямо через nginx-proxy)
   - Статика: `https://cdn.autoro.tech/*` (через GCore CDN)

2. **Создать отдельный поддомен для API**:
   - `api-blog.autoro.tech` → напрямую на nginx-proxy
   - `cdn.autoro.tech` → через GCore CDN для статики

---

## Проверка после очистки кеша

После очистки кеша:
1. Откройте DevTools → Network
2. Включите **"Disable cache"**
3. Перезагрузите страницу
4. Проверьте запросы к `/api/blog/admin/posts`
5. Они должны возвращать 401 (не 301)

---

## Если проблема останется

Если после очистки кеша проблема останется:
1. Проверьте правила в GCore CDN Rules
2. Проверьте настройки "Bypass API Cache"
3. Рассмотрите вариант прямого доступа к API (обходя CDN)
