# Диагностика Core Tunnel

## Проблема

Core Tunnel подключен, но:
- HTTPS Proxy отключен ✅ (исправлено)
- SOCKS Proxy включен на 127.0.0.1:1080 ✅
- НО: curl не работает через SOCKS proxy ❌

## Возможные причины

1. **Core Tunnel не слушает на порту 1080** - процесс может быть запущен, но порт не открыт
2. **Проблема с подключением Core Tunnel к серверу** - туннель показывает "Connected", но фактически не работает
3. **Проблема с конфигурацией SOCKS proxy** - возможно нужно использовать другой формат

## Диагностика

### Проверить процесс Core Tunnel

```bash
ps aux | grep -E "core|tunnel|coressh" | grep -v grep
```

### Проверить порт 1080

```bash
lsof -i :1080
netstat -an | grep 1080
nc -zv 127.0.0.1 1080
```

### Проверить подключение через SOCKS

```bash
curl -v --socks5-hostname 127.0.0.1:1080 http://www.google.com
```

## Решения

### Решение 1: Перезапустить Core Tunnel

1. Открыть приложение Core Tunnel
2. Отключить соединение
3. Подождать несколько секунд
4. Включить соединение снова

### Решение 2: Проверить подключение к серверу

Убедитесь, что SSH подключение к серверу работает:

```bash
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229 "echo 'Connection OK'"
```

### Решение 3: Использовать SSH туннель напрямую

Если Core Tunnel не работает, можно использовать SSH напрямую:

```bash
# Остановить Core Tunnel
# Затем запустить SSH туннель
ssh -i ~/.ssh/id_ed25519_autoro -D 1080 -N -f vladx@46.250.228.229

# Проверить
curl --socks5 127.0.0.1:1080 http://ifconfig.me
```

### Решение 4: Отключить прокси временно

Если нужно срочно выйти в интернет:

```bash
networksetup -setsocksfirewallproxystate "Wi-Fi" off
```

Затем включить обратно когда Core Tunnel заработает.
