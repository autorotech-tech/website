# Анализ стека и рекомендации для Autoro Blog

## 📊 Текущее состояние проекта

### Текущий стек
- **Next.js**: 14.2.14 (⚠️ устаревшая версия)
- **React**: 18.3.1 (⚠️ устаревшая версия)
- **Tailwind CSS**: 3.4.3 (⚠️ устаревшая версия, статья рекомендует v4)
- **Контент**: `react-markdown` (статья рекомендует Velite для MDX)
- **UI библиотеки**: Отсутствуют (статья рекомендует Shadcn UI)
- **База данных**: Supabase PostgreSQL
- **Развертывание**: Docker Compose

### Цели проекта
1. ✅ Простой легкий блог для привлечения трафика
2. ✅ Оптимизация GEO и SEO
3. ✅ Крутой дизайн и удобный UI
4. 🔄 Автоматическая отправка статей в индексы поисковиков
5. 🔄 Генерация контента для соцсетей
6. 🔄 Парсинг дизайна пользовательского сайта
7. 🔄 Микро-сервис для MVP и монетизации

## 🎯 Рекомендуемый стек (на основе исследования)

### Ядро (критично)
1. **Next.js 15** с App Router
   - React Server Components (RSC) по умолчанию
   - Улучшенное кэширование и ISR
   - Partial Prerendering (PPR) для производительности

2. **React 19**
   - Server Actions для форм и взаимодействий
   - Улучшенные хуки (use)

3. **Tailwind CSS v4**
   - Новый движок на Rust (Lightning CSS)
   - Конфигурация через CSS-переменные (@theme)
   - Мгновенная компиляция

### Слой данных
4. **Velite** (вместо react-markdown)
   - Типизация MDX через Zod
   - Валидация на этапе сборки
   - Полная поддержка RSC и ESM

5. **Rehype Pretty Code**
   - Подсветка синтаксиса на этапе сборки
   - Использует shiki (без клиентского JS)

### UI компоненты
6. **Shadcn UI** (базовые компоненты)
   - Copy-paste архитектура
   - Полный контроль над кодом
   - Интеграция с Tailwind

7. **Magic UI** или **Aceternity UI** (визуальные эффекты)
   - Микро-анимации
   - WOW-фактор для привлечения внимания

### Инструменты разработки
8. **Cursor + MCP**
   - Tailwind CSS MCP Server
   - Next.js Docs MCP
   - Filesystem MCP
   - Brave Search MCP (для дебаггинга)
   - Puppeteer MCP (для тестирования)

9. **.cursorrules**
   - Системные промпты для AI-ассистента
   - Единый стиль кода

## 📋 План миграции (Roadmap)

### Этап 1: Обновление ядра (Приоритет: ВЫСОКИЙ)
**Цель**: Обновить Next.js и React до актуальных версий

```bash
# В blog-autoro/
npm install next@latest react@latest react-dom@latest
```

**Риски**:
- Breaking changes в Next.js 15
- Необходимость обновления всех API routes
- Изменения в кэшировании fetch

**Время**: 2-4 часа

### Этап 2: Миграция на Tailwind CSS v4 (Приоритет: СРЕДНИЙ)
**Цель**: Обновить стили на новую версию

**Изменения**:
- Удалить `tailwind.config.js`
- Перейти на CSS-переменные (@theme)
- Обновить все классы (если есть breaking changes)

**Время**: 1-2 часа

### Этап 3: Внедрение Shadcn UI (Приоритет: ВЫСОКИЙ)
**Цель**: Добавить базовые компоненты

```bash
npx shadcn@latest init
npx shadcn@latest add card button badge separator avatar
```

**Время**: 30 минут

### Этап 4: Миграция на Velite (Приоритет: СРЕДНИЙ)
**Цель**: Заменить react-markdown на типизированный MDX

**Шаги**:
1. Установить Velite
2. Создать схемы для постов (Zod)
3. Настроить velite.config.ts
4. Мигрировать существующие посты

**Время**: 3-4 часа

### Этап 5: Визуальные эффекты (Приоритет: НИЗКИЙ)
**Цель**: Добавить "Wow-фактор"

- Magic UI для микро-анимаций
- Aceternity UI для сложных layout-эффектов

**Время**: 2-3 часа

### Этап 6: Создание .cursorrules (Приоритет: ВЫСОКИЙ)
**Цель**: Настроить AI-ассистента

**Время**: 30 минут

## ⚠️ Важные соображения

### Что НЕ нужно менять сейчас
1. **Supabase** - отлично работает, менять не нужно
2. **Docker Compose** - текущая настройка оптимальна
3. **Мультиязычность** - текущая реализация работает

### Что можно отложить
1. **Velite** - если текущий `react-markdown` работает, можно отложить
2. **Magic UI / Aceternity UI** - можно добавить позже для улучшения UX

### Критичные изменения
1. **Next.js 15** - необходим для производительности и SEO
2. **Shadcn UI** - упростит разработку UI компонентов
3. **.cursorrules** - ускорит разработку с AI

## 🚀 Быстрый старт (минимальные изменения)

Если нужно быстро улучшить проект без полной миграции:

1. **Добавить Shadcn UI** (30 минут)
   ```bash
   cd blog-autoro
   npx shadcn@latest init
   npx shadcn@latest add card button
   ```

2. **Создать .cursorrules** (15 минут)
   - См. файл `.cursorrules` в проекте

3. **Настроить MCP-серверы** (10 минут)
   ```bash
   ./add_mcp_servers.sh
   ```

4. **Обновить Next.js до 15** (2-3 часа)
   - Требует тестирования всех страниц
