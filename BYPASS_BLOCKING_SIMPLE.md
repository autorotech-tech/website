# Простое решение для обхода блокировки

## Вариант 1: Альтернативный домен через Cloudflare (САМОЕ ПРОСТОЕ)

Если у тебя есть другой домен (или можешь купить дешевый, например на Namecheap за $1/год):

1. Добавь домен в Cloudflare
2. Создай DNS записи с **Proxy включен** (оранжевое облако):
   ```
   autoro-alt.tld      A      46.250.228.229   (Proxy ON)
   *.autoro-alt.tld    A      46.250.228.229   (Proxy ON)
   ```
3. В Nginx на сервере добавь новый server_name:
   ```nginx
   server_name autoro.tech www.autoro.tech autoro-alt.tld *.autoro-alt.tld;
   ```
4. Используй новый домен: `https://swoop-autoro-alt.tld/admin/blog`

**Преимущества:**
- Работает сразу, без настройки туннелей
- Cloudflare скрывает реальный IP (Proxy ON)
- Бесплатно

---

## Вариант 2: Cloudflare Tunnel (если есть другой домен)

Если у тебя уже есть домен в Cloudflare:

1. На сервере запусти скрипт:
   ```bash
   bash ~/setup_cloudflare_tunnel.sh
   ```

2. Следуй инструкциям в скрипте

3. Используй новые домены:
   - `https://swoop-autoro.bypass.tech` (вместо swoop.autoro.tech)
   - `https://api-autoro.bypass.tech` (вместо api.autoro.tech)

**Преимущества:**
- Обходит блокировку IP
- Работает через HTTPS (как обычный сайт)
- Бесплатно

---

## Вариант 3: Мобильный интернет / Hotspot

Если блокировка только на стационарном интернете:
- Используй мобильный интернет
- Или создай hotspot с телефона

---

## Вариант 4: HTTP-прокси на другом сервере

Если у тебя есть другой VPS (не заблокированный):

1. Установи простой HTTP-прокси (например, `squid`)
2. Настрой прокси в браузере
3. Используй прокси для доступа к autoro.tech

---

## Рекомендация

**Используй Вариант 1** (альтернативный домен через Cloudflare Proxy) - это самое простое и быстрое решение.

Если нужно помочь с настройкой - скажи, у тебя есть другой домен или купить новый?
