**Ошибка:**
```

```

**Статус:** Файл `api/admin/posts/[id]/route.ts` уже использует правильный тип `Promise<{ id: string }>`, но TypeScript все еще видит старую сигнатуру.

**Возможные причины:**
1. Кеш TypeScript в Next.js
2. Проблема совместимости Next.js 16.1.1 с типами
3. Может потребоваться обновление до Next.js 15.x или более новой версии

**Временное решение (если нужно):**
Можно использовать type assertion в tsconfig.json или временно отключить строгую проверку типов для этого файла.
