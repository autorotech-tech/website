# Исправление ошибки 401 при загрузке файлов

## Проблема

После исправления редиректов при загрузке изображений возникает ошибка 401 Unauthorized.

## Решение

1. ✅ Создан файл `app/api/admin/upload/route.ts` с обработчиком загрузки
2. ✅ Исправлена ошибка TypeScript в `[id]/route.ts` (params стал Promise в Next.js 16)
3. ⚠️ Файлы скопированы на сервер
4. ⚠️ Контейнер пересобирается

## После пересборки контейнера

После успешной пересборки попробуйте загрузить изображение. Если все еще есть ошибка 401, проверьте:

1. **Логи контейнера:**
   ```bash
   docker logs autoro-blog-nextjs --tail 50
   ```

2. **Правильность токена авторизации:**
   - Убедитесь, что пользователь авторизован
   - Проверьте, что токен не истек

3. **Настройки Supabase Storage:**
   - Buckets `blog-images`, `blog-audio`, `blog-media` должны существовать
   - RLS политики должны быть настроены

4. **Переменные окружения:**
   - `SUPABASE_SERVICE_ROLE_KEY` должна быть установлена
   - `NEXT_PUBLIC_SUPABASE_URL` должна быть установлена
