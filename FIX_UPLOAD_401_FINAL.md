# Исправление 401 Unauthorized при загрузке файлов

## Проблема

POST запрос к `/api/blog/admin/upload` возвращает 401 Unauthorized, хотя токен передается в заголовке Authorization.

## Диагностика

Из логов видно ошибки: "Missing or invalid Authorization header"

Это означает, что:
1. Либо заголовок Authorization не передается правильно
2. Либо файл upload/route.ts не существует/не работает

## Решение

### Шаг 1: Проверить, существует ли файл в контейнере

Файл должен быть в:
- `/app/app/api/admin/upload/route.ts` (исходники)
- `/app/.next/server/app/api/admin/upload/route.js` (скомпилированный)

Если файла нет, нужно:
1. Скопировать файл в проект на сервере
2. Пересобрать контейнер

### Шаг 2: Проверить логи при POST запросе

```bash
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229
docker logs -f autoro-blog-nextjs
# Затем попробовать загрузить файл в браузере
```

### Шаг 3: Убедиться, что файл правильно обрабатывает multipart/form-data

Next.js 16 должен автоматически парсить FormData, но нужно проверить.

---

## Текущий статус

- ✅ OPTIONS запрос работает (204)
- ❌ POST запрос возвращает 401
- ⚠️ Файл upload/route.ts не найден в контейнере
- ⚠️ Есть ошибки компиляции при пересборке

---

## Временное решение

Пока файл не добавлен в контейнер, можно:
1. Использовать прямой доступ к Supabase Storage из фронтенда (как в других компонентах)
2. Или дождаться исправления ошибки компиляции и пересобрать контейнер
