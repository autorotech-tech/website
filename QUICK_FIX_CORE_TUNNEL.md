# Быстрое исправление: Core Tunnel не работает

## Проблема

Core Tunnel показывает "Connected", но порт 1080 не слушает и браузер не работает.

## Быстрое решение

### Вариант 1: Использовать SSH туннель напрямую (рекомендуется)

```bash
# Запустить SSH SOCKS5 туннель
ssh -i ~/.ssh/id_ed25519_autoro -D 1080 -N -f vladx@46.250.228.229

# Проверить
curl --socks5 127.0.0.1:1080 http://ifconfig.me
```

Если показывает IP `46.250.228.229` - значит работает!

### Вариант 2: Перезапустить Core Tunnel

1. Открыть приложение Core Tunnel
2. Отключить соединение
3. Подождать 5 секунд
4. Включить соединение снова
5. Проверить: `nc -zv 127.0.0.1 1080`

### Вариант 3: Временно отключить прокси

Если нужно срочно выйти в интернет:

```bash
networksetup -setsocksfirewallproxystate "Wi-Fi" off
```

Затем включить обратно когда туннель заработает:
```bash
networksetup -setsocksfirewallproxystate "Wi-Fi" on
```

## Текущие настройки

- ✅ SOCKS Proxy включен в System Settings: `127.0.0.1:1080`
- ❌ Порт 1080 не слушает (нужно запустить туннель)
- ✅ HTTPS Proxy отключен (исправлено)

## После запуска SSH туннеля

1. Порт 1080 начнет слушать
2. Браузер заработает через SOCKS proxy
3. Весь трафик будет идти через сервер 46.250.228.229

## Остановка SSH туннеля

```bash
pkill -f "ssh.*-D 1080"
```
