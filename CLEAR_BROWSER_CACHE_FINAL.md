# Финальное решение: Очистить кеш браузера

## Проблема

- ✅ Редиректы исправлены в GCore CDN (Redirect HTTP to HTTPS отключен)
- ✅ curl запросы работают правильно (401 без редиректа)
- ❌ Браузер показывает старые редиректы 301 из кеша

## Решение

### Шаг 1: Очистить кеш браузера

**Chrome/Edge:**
1. Откройте DevTools (F12 или Cmd+Option+I)
2. Откройте вкладку **Network**
3. Включите **"Disable cache"** (чекбокс вверху)
4. Кликните правой кнопкой на кнопку обновления страницы
5. Выберите **"Empty Cache and Hard Reload"** (Очистить кеш и жесткое обновление)

ИЛИ просто:

1. Нажмите **Cmd+Shift+R** (Mac) или **Ctrl+Shift+R** (Windows) - жесткое обновление
2. Если не помогло - включите "Disable cache" в DevTools → Network

### Шаг 2: Проверить работу

После очистки кеша:

1. Откройте `https://swoop.autoro.tech/admin/blog`
2. DevTools → Network → смотрите запросы к `/api/blog/admin/posts`
3. Запросы должны возвращать **401** (не 301)
4. Не должно быть `ERR_TOO_MANY_REDIRECTS`

### Шаг 3: Если проблема останется

Если после очистки кеша все еще есть проблемы:

1. **Полностью очистить кеш браузера:**
   - Chrome: Settings → Privacy and security → Clear browsing data
   - Выберите "Cached images and files"
   - Выберите "Last hour" или "All time"
   - Нажмите "Clear data"

2. **Использовать инкогнито режим:**
   - Откройте новое окно в режиме инкогнито
   - Перейдите на `https://swoop.autoro.tech/admin/blog`
   - Проверьте, работают ли запросы

3. **Проверить, что переменная окружения применена:**
   ```bash
   # На сервере
   curl -I 'https://cdn.autoro.tech/api/blog/admin/posts?page=1&limit=20' \
     -H 'Origin: https://swoop.autoro.tech'
   # Должен вернуть 401 (не 301)
   ```

---

## Почему это работает

После отключения "Redirect HTTP to HTTPS" в GCore CDN:
- ✅ Сервер больше не возвращает редиректы 301
- ✅ curl запросы работают правильно
- ❌ Браузер кешировал старые ответы с 301
- ✅ После очистки кеша браузер получит правильные ответы

---

## Проверка

После очистки кеша запросы должны работать:
- GET `/api/blog/admin/posts` → 401 (не 301)
- OPTIONS `/api/blog/admin/upload` → 204 (не 301)
- POST `/api/blog/admin/upload` → 200 или 401 (не 301)
