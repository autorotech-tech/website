## Управление

### Включить/отключить SOCKS proxy

Включить:
```bash
networksetup -setsocksfirewallproxystate "Wi-Fi" on
```

Отключить:
```bash
networksetup -setsocksfirewallproxystate "Wi-Fi" off
```

### Проверка работы

```bash
curl --socks5 127.0.0.1:1080 http://ifconfig.me
```

Должен показать IP сервера: `46.250.228.229`

### Управление Core Tunnel

- Открыть приложение: `open -a "Core Tunnel"`
- Закрыть: закрыть приложение Core Tunnel в macOS
