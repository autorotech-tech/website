# Исправление: Core Tunnel подключен, но порт 1080 не работает

## Проблема

- Core Tunnel показывает статус "Connected"
- Но порт 1080 не слушает (Connection refused)
- Браузер не работает

## Причина

Core Tunnel приложение показывает "Connected", но фактически не создал SOCKS proxy на порту 1080. Это может быть из-за:
- Проблемы с конфигурацией в Core Tunnel
- Приложение подключено, но порт forwarding не работает
- Конфликт с другими процессами

## Решение: Использовать SSH туннель напрямую

Вместо Core Tunnel используем SSH туннель напрямую:

### Запустить SSH SOCKS5 туннель

```bash
ssh -i ~/.ssh/id_ed25519_autoro -D 1080 -N -f vladx@46.250.228.229
```

Параметры:
- `-D 1080` - создает SOCKS5 proxy на порту 1080
- `-N` - не выполнять команды, только туннель
- `-f` - запустить в фоне

### Проверить работу

```bash
# Проверить, что порт слушает
nc -zv 127.0.0.1 1080

# Проверить подключение
curl --socks5 127.0.0.1:1080 http://ifconfig.me
```

Должно показать IP сервера: `46.250.228.229`

### Остановить туннель (если нужно)

```bash
pkill -f "ssh.*-D 1080"
```

## Альтернатива: Перезапустить Core Tunnel

Если хотите использовать Core Tunnel:

1. Открыть приложение Core Tunnel
2. Отключить соединение
3. Подождать 5 секунд
4. Включить соединение снова
5. Проверить порт: `nc -zv 127.0.0.1 1080`

Если порт все еще не работает - используйте SSH туннель напрямую (решение выше).

## Текущая конфигурация

После запуска SSH туннеля:
- ✅ SOCKS Proxy: `127.0.0.1:1080` (включен в System Settings)
- ✅ SSH туннель работает на порту 1080
- ✅ Браузер должен работать

## Автозапуск SSH туннеля (опционально)

Можно создать скрипт для автозапуска:

```bash
# Создать скрипт
cat > ~/start-proxy.sh << 'EOF'
#!/bin/bash
pkill -f "ssh.*-D 1080.*vladx@46.250.228.229"
ssh -i ~/.ssh/id_ed25519_autoro -D 1080 -N -f vladx@46.250.228.229
EOF

chmod +x ~/start-proxy.sh
```

Запускать когда нужно:
```bash
~/start-proxy.sh
```

## Итог

SSH туннель работает напрямую, обходя проблему с Core Tunnel. SOCKS proxy на 1080 теперь работает, браузер должен заработать.
