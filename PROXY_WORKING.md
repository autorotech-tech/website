Если браузер все еще не работает:
1. Перезапустите браузер
2. Очистите кеш браузера
3. Проверьте настройки proxy в браузере (должны быть системные)

## Управление

### Отключить proxy (когда не нужен)

```bash
networksetup -setsocksfirewallproxystate "Wi-Fi" off
```

### Включить proxy обратно

```bash
networksetup -setsocksfirewallproxystate "Wi-Fi" on
```
