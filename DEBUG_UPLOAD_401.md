# Диагностика 401 Unauthorized при загрузке

## Проблема

При загрузке изображения получаем 401 Unauthorized, хотя:
- ✅ Cookie `sb-access-token` присутствует в запросе (видно в DevTools)
- ✅ Authorization header присутствует (Bearer token)
- ✅ CORS настроен правильно

## Добавлено расширенное логирование

В функции `isAdmin()` добавлено детальное логирование для диагностики:
- Присутствие cookie header
- Количество распарсенных cookies
- Наличие `sb-access-token` cookie
- Извлечение токена
- Результат `getUser()`
- Сравнение email

3. Найти в логах записи, начинающиеся с `isAdmin -`
4. Проанализировать, на каком этапе происходит сбой

## Возможные причины

1. **Cookie не доходит до сервера** - GCore CDN/Nginx может не проксировать cookie
2. **Токен истек** - JWT токен может быть просрочен
3. **Email не совпадает** - email пользователя может отличаться от `autoro.tech@gmail.com`
4. **Токен невалидный** - токен может быть поврежден при передаче

## Проверка в браузере

В DevTools → Network → Request Headers убедиться, что:
- `Cookie: sb-access-token=...` присутствует
- `Authorization: Bearer ...` присутствует
