# Исправление: Core Tunnel не подключается - "Could not request local forwarding"

## Проблема

Core Tunnel показывает ошибку: **"Could not request local forwarding."**

Это означает, что порт 1080 уже занят другим процессом, и Core Tunnel не может открыть на нем SOCKS proxy.

## Решение

### Шаг 1: Остановить процесс, занимающий порт 1080

```bash
# Остановить SSH туннель (если запущен)
pkill -f "ssh.*-D 1080"

# Проверить, что порт свободен
lsof -i :1080
```

Если порт все еще занят, найти процесс вручную:

```bash
# Найти процесс на порту 1080
lsof -i :1080

# Остановить по PID (замените PID на реальный)
kill <PID>
```

### Шаг 2: Проверить, что порт свободен

```bash
lsof -i :1080
```

Должно быть пусто (порт свободен).

### Шаг 3: Подключиться через Core Tunnel

1. Откройте приложение Core Tunnel
2. Нажмите "Connect" для соединения "Unnamed"
3. Core Tunnel должен успешно подключиться и открыть порт 1080

### Шаг 4: Проверить работу

```bash
# Проверить, что порт 1080 слушает
lsof -i :1080

# Проверить подключение через proxy
curl --socks5 127.0.0.1:1080 http://ifconfig.me
```

Должно показать IP сервера: `46.250.228.229`

## Альтернатива: Использовать другой порт

Если нужно использовать Core Tunnel и SSH туннель одновременно, можно изменить порт в Core Tunnel на другой (например, 1081).

Но обычно достаточно использовать только один - либо Core Tunnel, либо SSH туннель напрямую.

## Итог

После остановки процесса, занимающего порт 1080, Core Tunnel сможет подключиться и создать SOCKS proxy на этом порту.
