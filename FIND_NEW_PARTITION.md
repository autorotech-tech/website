# Поиск нового раздела или нераспределенного пространства

## 🔍 Проблема:
`lsblk -f` не показывает новый раздел. Это может означать:
1. Раздел еще **не создан** (нужно создать на нераспределенном пространстве)
2. Диск расширен, но раздел не создан
3. Нужно проверить есть ли свободное место

## 📊 Анализ текущей ситуации:

Из вашего `lsblk`:
- `sda` - 75G (общий размер диска)
- `sda1` - 1M
- `sda2` - 2G (ext4)
- `sda3` - 73G (ext4)
- **Итого использовано:** ~75G

Если вы докупили место, но раздел не виден, нужно:
1. Проверить реальный размер диска
2. Найти нераспределенное пространство
3. Создать новый раздел

## 🔧 Шаг 1: Проверить детальную информацию о диске

```bash
# Более детальная информация
fdisk -l /dev/sda

# Или
parted /dev/sda print
```

**Что искать:**
- Общий размер диска (должен быть больше 75G если докупили место)
- Нераспределенное пространство (free space, unallocated)

## 🔧 Шаг 2: Если есть нераспределенное пространство

### Вариант A: Расширить существующий раздел sda3

```bash
# ⚠️ ОСТОРОЖНО! Это может быть рискованно на рабочем сервере
# Лучше создать новый раздел

# Использовать parted для расширения
parted /dev/sda
# В интерактивном режиме:
# (parted) resizepart 3
# End? [73GB]? 100%  # или новый размер
# (parted) quit

# Затем расширить файловую систему
resize2fs /dev/sda3
```

### Вариант B: Создать новый раздел (РЕКОМЕНДУЕТСЯ)

```bash
# 1. Использовать fdisk для создания нового раздела
fdisk /dev/sda

# В интерактивном режиме:
# - Нажать 'p' - посмотреть текущие разделы
# - Нажать 'n' - создать новый раздел
# - Выбрать 'p' - primary partition
# - Номер раздела: 4 (или следующий доступный)
# - First sector: нажать Enter (автоматически после sda3)
# - Last sector: нажать Enter (использовать все доступное место)
# - Нажать 'w' - записать изменения

# 2. После создания раздела, система может попросить перезагрузиться
# Но в rescue mode можно продолжить

# 3. Отформатировать новый раздел
mkfs.ext4 /dev/sda4

# 4. Примонтировать
mkdir -p /storage
mount /dev/sda4 /storage
```

## 🔧 Шаг 3: Использовать parted (более безопасно)

```bash
# 1. Посмотреть текущее состояние
parted /dev/sda print

# 2. Если есть свободное место, создать раздел
parted /dev/sda
# В интерактивном режиме:
# (parted) print  # посмотреть текущее состояние
# (parted) mkpart primary ext4 <start> <end>
# Например: mkpart primary ext4 75GB 100%
# (parted) quit

# 3. Отформатировать
mkfs.ext4 /dev/sda4

# 4. Примонтировать
mkdir -p /storage
mount /dev/sda4 /storage
```

## 📋 Полная последовательность команд:

```bash
# === В CHROOT (после mount /dev/sda3 /mnt и chroot) ===

# 1. Проверить детальную информацию
fdisk -l /dev/sda
# Или
parted /dev/sda print

# 2. Если видите свободное место (free space), создать раздел
# Используя fdisk:
fdisk /dev/sda
# Команды в fdisk:
# p - посмотреть разделы
# n - новый раздел
# p - primary
# 4 - номер раздела
# Enter - начальный сектор (по умолчанию)
# Enter - конечный сектор (все доступное место)
# w - записать и выйти

# 3. После создания раздела, проверить
lsblk -f

# 4. Отформатировать новый раздел
mkfs.ext4 /dev/sda4

# 5. Примонтировать
mkdir -p /storage
mount /dev/sda4 /storage

# 6. Получить UUID и добавить в fstab
blkid /dev/sda4
cp /etc/fstab /etc/fstab.backup
echo "UUID=<uuid>  /storage  ext4  defaults  0  2" >> /etc/fstab

# 7. Проверить
mount -a
df -h | grep storage
```

## ⚠️ ВАЖНО перед созданием раздела:

1. **Проверьте размер диска:**
   ```bash
   fdisk -l /dev/sda | grep "Disk /dev/sda"
   ```
   Должен показывать новый размер (больше 75G)

2. **Проверьте свободное место:**
   ```bash
   parted /dev/sda print free
   ```

3. **Сделайте backup таблицы разделов:**
   ```bash
   sfdisk -d /dev/sda > /root/partitions_backup.txt
   ```

## 🔍 Если диск не расширен:

Если `fdisk -l` показывает что диск все еще 75G, значит:
- Провайдер еще не расширил диск
- Нужно обратиться в поддержку Contabo
- Или проверить в панели управления что диск действительно расширен
