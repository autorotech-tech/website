# Правильное подключение Simple Memory

## Проблема
Simple Memory получает промпт агента вместо пользовательского сообщения. Память не видит реальные вопросы пользователя.

## Решение: Память должна отслеживать входы/выходы агента автоматически

В Langchain память работает автоматически - она отслеживает:
- **Input**: сообщения пользователя (что передаётся в агента через main)
- **Output**: ответы агента (что возвращает агент)

Но сейчас агент получает сложный промпт, а не просто текст пользователя.

## Вариант 1: Подключить память правильно (РЕКОМЕНДУЕТСЯ)

Память НЕ должна получать данные из Filter Chat Action Output напрямую!

**Правильная структура:**

```
Filter Chat Action Output
  ↓ main (текст пользователя + метаданные)
Multilingual AI Agent
  ↑ ai_memory (память подключается сюда)
Simple Memory (автоматически отслеживает input/output агента)
```

**Что сделать:**

1. **Отключите** любые связи между Filter Chat Action Output и Simple Memory

2. **Simple Memory** должен быть подключен ТОЛЬКО к агенту:
   - Simple Memory (ai_memory) → Multilingual AI Agent (ai_memory)

3. **Убедитесь, что агент получает простой текст** (не промпт) через main порт:
   - Filter Chat Action Output (main) → Multilingual AI Agent (main)

4. **В Simple Memory:**
   - Session Key: `={{ $json.chat_id }}`
   - Context Window Length: `10` (или больше)

Память автоматически будет отслеживать:
- Что приходит в агента через main (пользовательские сообщения)
- Что возвращает агент (ответы)

## Вариант 2: Передать chat_id через агента

Если память не видит chat_id, нужно передать его через поток:

В узле **"Filter Chat Action Output"** убедитесь, что передаётся:
- `text` - сообщение пользователя
- `chat_id` - для сессии памяти

В **"Multilingual AI Agent"** промпт должен использовать `$json.text` (простой текст), а не весь промпт.

## Вариант 3: Использовать Session Memory (проще)

Если Simple Memory не работает, используйте **"Session Memory"**:

1. Удалите Simple Memory
2. Добавьте **"Session Memory"**
3. Подключите: Session Memory (ai_memory) → Multilingual AI Agent (ai_memory)
4. Session ID: `={{ $json.chat_id }}`

Session Memory работает через n8n переменные и более надёжен.

## Критическое исправление промпта

В промпте агента вы используете `{{ $json.text }}` - это правильно. Но убедитесь, что:

1. В **"Filter Chat Action Output"** передаётся поле `text` с реальным вопросом пользователя
2. Агент получает `text` напрямую, а не через сложный промпт

Проверьте INPUT узла "Multilingual AI Agent" - там должен быть `text` с вопросом пользователя.
