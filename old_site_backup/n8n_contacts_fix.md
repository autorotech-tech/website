# Исправление проблемы с контактами из БЗ

## Проблема
Агент не включает контакты из Базы Знаний в ответы на вопросы о гидах, экскурсиях и т.д.

## Решение

### 1. Обновить System Message в "Multilingual AI Agent"

Откройте узел **"Multilingual AI Agent"** → вкладка **"System Message"** → замените на:

```json
{
  "role": "AI-ассистент-гид по острову Фукуок",
  "task": "Дай полный, конкретный ответ. Сначала используй Базу Знаний.",
  "context": {
    "user_question": "{{ $json.text }}",
    "user_language": "{{ $json.detected_language }}"
  },
  "instructions": [
    "Язык ответа: СТРОГО {{ $json.detected_language }}.",
    "Запрещена персонификация: пляжи, парки НЕ «советуют».",
    "Полнота: ответ должен быть законченным, не обрезанным.",
    "Контакты: ОБЯЗАТЕЛЬНО ищи контакты в БЗ по теме вопроса. Если в БЗ есть релевантные контакты (telegram, sites, phones, emails) - включи их в поле contacts. Контакты включай ТОЛЬКО из БЗ.",
    "Формат вывода: ТОЛЬКО JSON без код-блоков: {\"answer\": string, \"contacts\": {\"telegram\": string[], \"sites\": string[], \"phones\": string[], \"emails\": string[]}, \"sources\": string[]}",
    "answer: кратко, по делу, списки маркерами «• ».",
    "Если точных данных нет — честно скажи; contacts могут быть пустыми."
  ]
}
```

### 2. Проверить настройки "Answer questions with a vector store"

Откройте узел **"Answer questions with a vector store"**:

- **Limit (topK)**: установите `7-10` (увеличьте для получения большего количества релевантных документов)
- Убедитесь, что узел правильно подключен к **Multilingual AI Agent** и передает контекст из БЗ

### 3. Проверить подключение узлов

Убедитесь, что поток данных:
```
[Answer questions with a vector store] → [Multilingual AI Agent]
```

Multilingual AI Agent должен получать контекст из векторного поиска.

### 4. Сохранить и протестировать

1. Нажмите **"Save"** (Ctrl+S / Cmd+S)
2. Протестируйте с вопросами:
   - "где найти гида?"
   - "где купить экскурсии?"
   - "контакты VinWonders"
3. Проверьте, что в ответе есть поле `contacts` с данными из БЗ

## Ожидаемый результат

После исправления:
- ✅ Агент всегда ищет контакты в БЗ по теме вопроса
- ✅ Если контакты найдены в БЗ - они ОБЯЗАТЕЛЬНО включаются в ответ
- ✅ Ответ содержит конкретные контакты (telegram, sites, phones, emails) из БЗ
- ✅ Нет общих ответов без проверки БЗ
