# Инструкции по оптимизации workflow для сайта

## Проблема
- Workflow выполняется 60+ секунд
- Ответ не доходит до чата
- Нужна оптимизация скорости

## Решения

### 1. Оптимизация Supabase Knowledge Search

**В узле "Answer questions with a vector store":**
- Измените `topK` с `10` на `5` (меньше запросов = быстрее)
- Это уменьшит время поиска в базе знаний

**В узле "Supabase Knowledge Search":**
- Проверьте, что используется правильная таблица `documents_pquoc`
- Убедитесь, что индексы настроены для быстрого поиска

### 2. Оптимизация промпта агента

**В узле "Multilingual AI Agent" → System Message:**

Замените текущий промпт на оптимизированную версию:

```json
{
  "role": "AI-ассистент",
  "task": "Дай краткий и полезный ответ, используя ТОЛЬКО инструменты: База Знаний и Погода.",
  "context": {
    "user_question": "{{ $json.text }}",
    "user_language": "{{ $json.detected_language }}"
  },
  "instructions": [
    "Язык ответа: СТРОГО {{ $json.detected_language }}.",
    "ВАЖНО: Ответ должен быть КРАТКИМ - максимум 200-300 слов. Не пиши длинные планы детально.",
    "Алгоритм: 1) Поиск в базе знаний (topK=5). 2) Выбери самые релевантные 3-5 фактов. 3) Сформулируй краткий ответ.",
    "В ответ включай ТОЛЬКО факты и контакты из базы знаний. Не выдумывай.",
    "Если явно спрашивают про погоду: определи координаты и вызови инструмент Погода.",
    "Если база знаний не покрывает запрос — честно скажи об этом кратко.",
    "Формат: обычный текст. Списки — маркеры «• ». Без HTML.",
    "Структура: • Короткий вывод (1–2 предложения). • Список основных пунктов (3-5). • При наличии — контакты/ссылки.",
    "Стиль: дружелюбно, по делу, без воды. НЕ расписывай детально каждый день."
  ]
}
```

### 3. Проверка таймаутов

**В chat-proxy (server.js):**
```js
// Увеличьте таймаут запроса к n8n
const response = await fetch(n8nUrl, {
  method: 'POST',
  headers: { ... },
  body: JSON.stringify(payload),
  timeout: 120000 // 120 секунд
});
```

**В Nginx конфигурации:**
```nginx
proxy_read_timeout 120s;
proxy_connect_timeout 10s;
proxy_send_timeout 120s;
```

### 4. Оптимизация размера ответа

**В узле "Build Response" уже добавлено:**
- Ограничение длины до 3000 символов
- Финальная фраза

**Дополнительно - проверка размера перед отправкой:**

В узле "Respond to Webhook":
- Убедитесь, что `Response Body` = `{{$json}}`
- Это правильно - весь объект отправляется

### 5. Оптимизация памяти (Simple Memory)

**Проблема:** Memory может замедлять запросы

**Решение:** Временно отключите "Simple Memory" для тестирования скорости

Или настройте:
- `Session Key` должен быть уникальным для каждой сессии
- Проверьте, что память не блокирует запросы

### 6. Мониторинг производительности

**В n8n Executions:**
- Проверьте, какой узел занимает больше всего времени
- Если "Supabase Knowledge Search" - это проблема с базой
- Если "Multilingual AI Agent" - оптимизируйте промпт

## Быстрые исправления

1. **Уменьшить topK до 5** в "Answer questions with a vector store"
2. **Сократить промпт** - добавить инструкцию "максимум 200-300 слов"
3. **Увеличить таймауты** везде до 120 секунд
4. **Проверить размер ответа** - если > 5000 символов, обрезать

## Проверка после оптимизации

1. Отправьте запрос в чат
2. Проверьте время выполнения в Executions (должно быть < 30 секунд)
3. Проверьте, доходит ли ответ до чата
