# Исправление Simple Memory - окончательное решение

## Проблема
Память подключена, но бот не помнит предыдущие сообщения.

## Причина
Simple Memory подключен к агенту, но не получает данные из основного потока (chat_id и сообщения).

## Решение: Правильное подключение памяти

### Вариант 1: Подключить память к потоку данных (РЕКОМЕНДУЕТСЯ)

1. **Отключите** текущее подключение Simple Memory от Multilingual AI Agent

2. **Подключите память к потоку данных**:
   - От **"Filter Chat Action Output"** → порт `main` → к **"Simple Memory"** → порт `main`
   - От **"Simple Memory"** → порт `ai_memory` → к **"Multilingual AI Agent"** → порт `ai_memory`

3. **В Simple Memory** убедитесь:
   - **Session Key**: `={{ $json.chat_id }}`
   - **Session Key Type**: `customKey`

### Вариант 2: Использовать Summary Memory или Postgres Memory

Если Simple Memory не работает, попробуйте:

1. Удалите "Simple Memory"
2. Добавьте **"Summary Memory"** (для экономии токенов) или **"Postgres Chat Memory"** (для персистентности)
3. Подключите аналогично: поток → память → агент
4. Session ID: `={{ $json.chat_id }}`

### Вариант 3: Проверить параметры Buffer Window

Если используете "Buffer Window Memory", проверьте:

1. Откройте **"Simple Memory"** → **Options**
2. Найдите **"Return Messages"** или **"Window Size"**
3. Установите: **10-20** (количество сообщений в истории)
4. Убедитесь, что **"Return Messages"** включен

## Обновление промпта для использования памяти

В узле **"Multilingual AI Agent"** добавьте в промпт инструкцию использовать историю:

## Диагностика

Чтобы проверить, работает ли память:

1. Откройте последнее выполнение в n8n → Executions
2. Посмотрите на узел **"Simple Memory"**:
   - Проверьте **INPUT** - должен быть `chat_id` и данные сообщения
   - Проверьте **OUTPUT** - должна быть история (если не первое сообщение)
3. Проверьте узел **"Multilingual AI Agent"**:
   - Во **INPUT** должна быть история из памяти

## Правильная структура потока

```
Filter Chat Action Output
  ↓ main
Simple Memory (sessionKey = chat_id, получает данные из потока)
  ↓ ai_memory
Multilingual AI Agent (использует память)
  ↓ main
Format response
```

## Если ничего не помогает

Попробуйте использовать **Postgres Chat Memory**:
1. Он более надёжен для production
2. Хранит историю между перезапусками n8n
3. Настройка аналогична, но требует PostgreSQL
