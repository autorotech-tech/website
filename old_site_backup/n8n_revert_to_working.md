# Восстановление рабочего состояния workflow

## Проблема
После моих правок workflow перестал работать корректно:
- Ответы не релевантные
- Кривое форматирование
- Контакты не извлекаются из БЗ

## Решение: Вернуть System Message к рабочей версии

### System Message (простая рабочая версия)

**Откройте узел "Multilingual AI Agent"** → вкладка **"System Message"** → замените на:

```json
{
  "role": "AI-ассистент-гид по острову Фукуок",
  "task": "Дай полный, конкретный ответ. Сначала используй Базу Знаний.",
  "context": {
    "user_question": "{{ $json.text }}",
    "user_language": "{{ $json.detected_language }}"
  },
  "instructions": [
    "Язык ответа: СТРОГО {{ $json.detected_language }}.",
    "Запрещена персонификация: пляжи, парки НЕ «советуют».",
    "Полнота: ответ должен быть законченным, не обрезанным.",
    "Контакты: включай ТОЛЬКО из БЗ. В контексте вопроса (VinWonders → контакты для билетов VinWonders).",
    "Формат вывода: ТОЛЬКО JSON без код-блоков: {\"answer\": string, \"contacts\": {\"telegram\": string[], \"sites\": string[], \"phones\": string[], \"emails\": string[]}, \"sources\": string[]}",
    "answer: кратко, по делу, списки маркерами «• ».",
    "Если точных данных нет — честно скажи; contacts могут быть пустыми."
  ]
}
```

**Важно**: 
- Убрать все дополнительные инструкции про контакты
- Убрать упоминания про "кликабельные ссылки" в System Message
- Оставить простую версию, которая работала

### Проверка узла "Answer questions with a vector store"

Убедитесь что в **Description** есть:
```
Используй этот инструмент, чтобы отвечать на вопросы о путешествиях на остров Фукуок (Phu Quoc), включая туры, цены, визы, транспорт и достопримечательности. Всегда отдавай приоритет информации в базе знаний, ссылкам и контактам касающихся запроса.
```

Это должно быть достаточно - инструкция про контакты уже есть в description узла.

### Проверка узла "Format Links for Web"

Убедитесь что узел "Format Links for Web" форматирует контакты в текст. Это должно быть в коде узла, а не в System Message.

### Сохранение

1. Нажмите **"Save"** (Ctrl+S / Cmd+S)
2. Протестируйте с вопросом "где купить экскурсии и туры?"
3. Проверьте что контакты извлекаются из БЗ

## Что было убрано

- ❌ Убраны дополнительные инструкции про контакты
- ❌ Убраны упоминания про "кликабельные ссылки" в System Message
- ❌ Убраны дублирования инструкций
- ✅ Оставлена простая рабочая версия
