# Диагностика n8n workflow для сайта

## Проблема
Сервер возвращает дефолтный ответ `{"reply":"Thanks! We will get back to you shortly."}` вместо реального ответа от агента.

## Диагностика в n8n

### Шаг 1: Проверьте последнее выполнение

1. Откройте n8n → Workflows → ваш workflow для сайта
2. Перейдите в вкладку **"Executions"**
3. Откройте последнее выполнение (самое свежее)
4. Проверьте, какие узлы выполнились:

**Должны выполниться:**
- ✅ Webhook
- ✅ Normalize From Site
- ✅ Extract Message Data
- ✅ Detect Language
- ✅ Merge
- ✅ Process & Combine Data
- ✅ Filter Chat Action Output
- ❓ **Multilingual AI Agent** (ПРОВЕРЬТЕ - выполнился ли?)
- ❓ **Format Links for Web** (если добавлен)
- ❓ **Build Response**

### Шаг 2: Проверьте OUTPUT узла "Multilingual AI Agent"

1. В последнем выполнении откройте узел **"Multilingual AI Agent"**
2. Посмотрите **OUTPUT** этого узла
3. Должно быть поле `output` или `answer` с текстом ответа

**Если OUTPUT пустой или есть ошибка:**
- Агент не выполнился
- Возможна проблема с креденшалами (Gemini, Supabase)
- Возможна проблема с подключением памяти

### Шаг 3: Проверьте узел "Build Response"

Откройте OUTPUT узла **"Build Response"**:
- Если там всегда `{"reply": "Thanks! We will get back to you shortly."}`, значит агент не передал ответ

**Проверьте код узла "Build Response":**
```js
return [{ 
  json: { 
    reply: $json.formatted_reply || $json.original_reply || $json.output || $json.answer || 'Спасибо! Скоро ответим.'
  } 
}];
```

Если агент не вернул `output` или `answer`, будет использоваться дефолт.

### Шаг 4: Проверьте ошибки в Execution

В последнем выполнении:
- Есть ли красные узлы (ошибки)?
- Какие ошибки показываются?

## Возможные причины

### Причина 1: Агент не выполняется
- **Симптом**: В Executions узел "Multilingual AI Agent" красный или пропущен
- **Решение**: Проверьте креденшалы Gemini и Supabase

### Причина 2: Память блокирует выполнение
- **Симптом**: Агент зависает на получении памяти
- **Решение**: Временно отключите Simple Memory и проверьте работу

### Причина 3: Агент возвращает пустой ответ
- **Симптом**: Агент выполнился, но OUTPUT пустой
- **Решение**: Проверьте промпт и System Message

### Причина 4: Build Response получает неправильные данные
- **Симптом**: Агент вернул ответ, но Build Response его не видит
- **Решение**: Проверьте соединения между узлами

## Быстрая проверка

Выполните тест напрямую в n8n:

1. Откройте workflow в редакторе
2. Нажмите **"Execute Workflow"** (красная кнопка внизу)
3. Используйте **Test URL** из узла Webhook
4. Или вручную установите данные:
   ```json
   {
     "session": "test123",
     "lang": "ru",
     "message": "какие туры доступны?"
   }
   ```
5. Посмотрите, какие узлы выполнились и что в OUTPUT каждого узла

## Проверка мигающих точек

Если точки не видны, проверьте:
1. CSS загружен (`chat.css`)
2. Класс `chat-typing-dots` применяется
3. Анимация работает (проверьте в Elements)

Проверьте, что статус поиска отображается хотя бы на момент до получения ответа.
