# Оптимизация памяти - сохранение только необходимых данных

## Проблема
Память сохраняет весь огромный промпт с инструкциями вместо простого текста сообщения пользователя и ответа.

## Решение: Изменить способ передачи данных в агента

### Шаг 1: Изменить Source for Prompt в Multilingual AI Agent

В узле **"Multilingual AI Agent"**:

1. Найдите параметр **"Source for Prompt (User Message)"**
2. Измените с **"Define below"** на **"Use Input Data"**
3. В поле **"Prompt (User Message)"** укажите: `={{ $json.text }}`

Это передаст в агента только текст сообщения пользователя, а не весь промпт.

### Шаг 2: Переместить инструкции в System Message

Инструкции нужно переместить в системное сообщение агента:

1. В узле **"Multilingual AI Agent"** → **Settings** (или **Options**)
2. Найдите **"System Message"** или **"System Prompt"**
3. Добавьте системное сообщение:

```
Ты - AI-ассистент для помощи в вопросах о путешествиях на остров Фукуок.

Язык ответа: используй язык пользователя.

КРИТИЧЕСКИ ВАЖНО:
1. Используй Базу Знаний для ВСЕХ вопросов о Фукуоке.
2. Если в базе знаний нет информации - НЕ выдумывай контакты, телефоны, email или адреса.
3. Если база знаний не содержит ответа, скажи честно.
4. Включай в ответ ТОЛЬКО те контакты, ссылки и данные, которые реально есть в базе знаний.
5. Используй историю диалога из памяти для ответов на вопросы о предыдущих сообщениях.

Если пользователь спрашивает о погоде - используй инструмент Погода с координатами.
Не упоминай инструменты.
Формат: ТОЛЬКО Telegram HTML (<b>, <i>, <u>, <s>, <a href='...'>, <code>, <pre>).
ЗАПРЕТ: <p>, <ul>, <li>. Абзацы через \n.
СПИСКИ: \n• Пункт 1\n• Пункт 2.
Стиль: полезный, точный, дружелюбный, с эмодзи.
```

### Шаг 3: Упростить промпт

Если нет возможности использовать System Message, упростите промпт в "Define below":

**Старый промпт (сложный):**
```json
{
  "role": "AI-ассистент",
  "task": "...",
  "context": {...},
  "instructions": [...]
}
```

**Новый упрощённый промпт:**
```
{{ $json.text }}
```

Или просто удалите "Define below" и используйте "Use Input Data" с `={{ $json.text }}`.

### Альтернатива: Использовать Code node для подготовки данных

Если настройки агента не позволяют легко изменить источник, добавьте узел **Code** перед агентом:

**Название**: "Prepare Agent Input"

**Код**:
```js
// Извлекаем только текст пользователя и chat_id
const userText = $json.text || '';
const chatId = $json.chat_id || '';

// Возвращаем только необходимые данные
return [{
  json: {
    // Только текст сообщения пользователя
    text: userText,
    chat_id: chatId,
    detected_language: $json.detected_language || 'en',
    platform: $json.platform || 'telegram'
  }
}];
```

Затем в агенте используйте `{{ $json.text }}` как промпт.

## Результат

После этих изменений память будет сохранять:
- **Input**: Простой текст сообщения пользователя (например: "привет, какие туры лучше посетить?")
- **Output**: Ответ агента (без всего промпта)
- **Session Key**: `chat_id`

Вместо текущего огромного JSON с инструкциями.

## Проверка

После изменений проверьте в Simple Memory OUTPUT:
- Должны быть только HumanMessage с текстом пользователя
- И AIMessage с ответом агента
- Без всего промпта и инструкций
