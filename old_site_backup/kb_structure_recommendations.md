# Рекомендации по структуре Базы Знаний для векторного поиска

## Проблема
Агент не использует информацию и контакты из БЗ. Нужна оптимальная структура для векторного поиска.

## Оптимальная структура документов для векторного поиска

### 1. Структура одного документа в Supabase

Каждый документ должен иметь следующую структуру:

```json
{
  "content": "Текст документа с информацией",
  "metadata": {
    "category": "направление/категория",
    "service_type": "тип услуги",
    "title": "название",
    "contacts": {
      "telegram": ["@username", "https://t.me/channel"],
      "sites": ["https://example.com"],
      "phones": ["+84 123 456 789", "0123456789"],
      "emails": ["info@example.com"]
    },
    "keywords": ["ключевое слово 1", "ключевое слово 2"],
    "location": "место",
    "price_range": "диапазон цен",
    "tags": ["тег1", "тег2"]
  }
}
```

### 2. Организация по направлениям

**Рекомендуемая структура разделов:**

#### A. Экскурсии и туры
```
Раздел: Экскурсии и туры на Фукуоке

Подразделы:
- Морские экскурсии
- Экскурсии по острову (север/юг)
- Винные туры
- Рыбалка и дайвинг
- Экскурсии в парки развлечений

Каждый подраздел должен содержать:
1. Описание услуги
2. Что включено
3. Длительность
4. Цены
5. КОНТАКТЫ для бронирования (телефон, telegram, сайт)
6. Когда бронировать
```

#### B. Транспорт
```
- Трансферы из аэропорта
- Аренда мотоциклов/автомобилей
- Такси
- Аренда лодок
```

#### C. Размещение
```
- Отели
- Виллы
- Апартаменты
```

#### D. Парки и развлечения
```
- VinWonders
- Vinpearl Safari
- Океанариум
- Водные парки
```

#### E. Пляжи
```
- Описание пляжей
- Инфраструктура
- Как добраться
```

#### F. Рестораны и еда
```
- Рестораны по типам кухни
- Кафе
- Рыбные рынки
```

### 3. Формат текста для оптимального поиска

**Правило**: Каждый документ должен быть самодостаточным ответом на вопрос.

**Пример правильного формата:**

```
# Экскурсии на остров Фукуок

## Морские экскурсии

Морские экскурсии - один из самых популярных видов активностей на Фукуоке. 
Включают посещение островов, снорклинг, рыбалку.

**Что включено:**
• Трансфер из отеля
• Обед на лодке
• Снаряжение для снорклинга
• Гид

**Длительность:** 6-8 часов
**Цена:** от $45-60 за человека (в пик сезона до $80-130)

**Где купить экскурсии:**
• Telegram: @phuquoc_tours
• Сайт: https://phuquoc-tours.com
• Телефон: +84 123 456 789
• Email: info@phuquoc-tours.com

**Когда бронировать:** Рекомендуется за 1-2 месяца до поездки, особенно в высокий сезон.

**Важно:** В праздники (Тет) цены могут удваиваться.
```

### 4. Ключевые принципы

#### A. Контакты должны быть В ТЕКСТЕ документа
```
НЕПРАВИЛЬНО (только в metadata):
{
  "content": "Экскурсии можно купить...",
  "metadata": {"contacts": {...}}
}

ПРАВИЛЬНО (в тексте И в metadata):
{
  "content": "Экскурсии можно купить через Telegram @phuquoc_tours, сайт https://phuquoc-tours.com, телефон +84 123 456 789",
  "metadata": {"contacts": {"telegram": ["@phuquoc_tours"], "sites": ["https://phuquoc-tours.com"], "phones": ["+84 123 456 789"]}}
}
```

#### B. Используйте ключевые слова в тексте
```
Вопрос: "где купить экскурсии"
Документ должен содержать: "купить экскурсии", "забронировать туры", "где приобрести"
```

#### C. Структурируйте по вопросам
Каждый документ должен отвечать на конкретный вопрос:
- "Где купить экскурсии на Фукуоке?"
- "Как забронировать трансфер?"
- "Где найти гида?"

### 5. Пример структурированного документа

```markdown
# Где купить экскурсии и туры на Фукуоке

### 1. Онлайн через сайты и приложения

**Сайты:**

**Телефоны:**

**Email:**
• info@phuquoc-tours.com - общие вопросы
• booking@phuquoc-tours.com - бронирование

### 2. Местные туристические агентства

В центре Дуонг Донг расположены офисы:
• Агентство "Phu Quoc Travel" - ул. Транг, 123
• Телефон: +84 555 123 456

### 3. Через отели

Многие отели предлагают экскурсии через консьерж-сервис.

### 4. На месте у водителей и гидов

Можно договориться с лицензированными гидами, но цены могут быть выше.

## Рекомендации

• Бронируйте за 1-2 месяца до поездки
• В пик сезона (Тет) цены могут удваиваться

```

### 6. Metadata для векторного поиска

```json
{
  "metadata": {
    "category": "экскурсии",
    "service_type": "бронирование",
    "keywords": ["купить экскурсии", "забронировать туры", "где купить", "экскурсии фукуок"],
    "contacts": {
      "telegram": ["@phuquoc_excursions", "@phuquoc_tours_ru"],
      "sites": ["https://phuquoc-tours.com", "https://vinwonders.com"],
      "phones": ["+84 123 456 789", "+84 987 654 321"],
      "emails": ["info@phuquoc-tours.com", "booking@phuquoc-tours.com"]
    },
    "location": "Фукуок",
    "price_range": "$45-130",
    "tags": ["экскурсии", "туры", "бронирование", "контакты"]
  }
}
```

### 7. Обновление System Message

После структурирования БЗ, обновить System Message:

```json
{
  "instructions": [
    "...",
    "Контакты: ВСЕГДА ищи контакты в найденных документах БЗ. Контакты могут быть в тексте документа или в метаданных. Если вопрос про «где купить/как связаться» — обязательно включи все найденные контакты в ответ.",
    "Формат контактов в ответе: включай контакты органично в текст answer, а также в поле contacts JSON."
  ]
}
```

## Рекомендации по загрузке данных

### 1. Разбить большой документ на секции
- Каждая секция = отдельный документ в БЗ
- Каждая секция должна быть самодостаточной
- Размер: 200-500 слов на документ

### 2. Для каждого типа услуги создать отдельный документ
- "Где купить экскурсии" → отдельный документ
- "Где купить билеты в VinWonders" → отдельный документ
- "Где найти гида" → отдельный документ

### 3. Контакты должны быть явными
- В тексте документа: "Telegram: @username"
- В метаданных: структурированный JSON
- Использовать ключевые слова: "купить", "забронировать", "контакты"

## Инструменты для работы с PDF

Для работы с PDF в n8n можно использовать:
1. **n8n-nodes-base.readBinaryFile** - чтение PDF
2. **pdf-parse** (через Code node) - парсинг PDF
3. **pdf-lib** (через Code node) - работа с PDF

Но лучше конвертировать PDF в структурированный формат (Markdown/JSON) и загружать в Supabase.
