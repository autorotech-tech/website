# Оптимизация Базы Знаний для векторного поиска

## Критическая проблема
Контакты должны быть **В ТЕКСТЕ** документа, а не только в метаданных, потому что агент видит только `content` документов.

## Оптимальная структура документа

### Формат для "Где купить экскурсии"

```markdown
# Где купить экскурсии и туры на Фукуоке

Экскурсии и туры на Фукуоке можно приобрести несколькими способами:

## 1. Онлайн через Telegram и сайты

**Telegram каналы для бронирования:**
• @PhuQuoc_guide_bot - официальный бот для заказа экскурсий
• @PhuQuocVietnamRest - канал с актуальными предложениями
• @phuquoc_vietnam - основной канал экскурсий

**Веб-сайты:**
• https://pquoc.com - официальный сайт бронирования экскурсий
• https://www.facebook.com/islandsvacations - страница в Facebook
• https://www.instagram.com/vlad_phu_quoc_guide/ - Instagram с примерами туров

## 2. Местные туристические агентства

В центре города Дуонг Донг расположены офисы туристических агентств, где можно купить групповые туры:
• Морские прогулки
• Экскурсии на север/юг острова
• Винные туры

## 3. Через отели

Многие отели предлагают экскурсии через консьерж-сервис.

## 4. На месте у водителей и гидов

Можно договориться с лицензированными гидами, но цены могут быть выше, особенно в праздники.

## Рекомендации по бронированию

• **Бронируйте заранее**: Рекомендуется за 1-2 месяца до поездки
• **В пик сезона**: Во время Тет цены могут удваиваться (от $80-130 вместо $45-60)
• **Пакетные туры**: С перелетом часто выгоднее, чем покупка на месте

## Важно

В пиковый сезон билеты в крупные парки (VinWonders, Safari) можно забронировать только заранее через агентства.
```

## Правила структурирования

### 1. Каждый документ = ответ на конкретный вопрос
- ❌ Один большой документ "Все о Фукуоке"
- ✅ Множество документов: "Где купить экскурсии", "Где найти гида", "Как забронировать трансфер"

### 2. Контакты должны быть в тексте
- ✅ В тексте: "Telegram: @PhuQuoc_guide_bot"
- ✅ В метаданных: дублирование для структурированного поиска

### 3. Используйте ключевые слова
Вопрос: "где купить экскурсии"
Текст должен содержать: "купить экскурсии", "забронировать туры", "где приобрести", "контакты для бронирования"

### 4. Размер документа
- Оптимально: 200-500 слов
- Максимум: 1000 слов
- Слишком длинные документы разбивать на секции

## Пример структурированного раздела

# Где найти гида на Фукуоке

Найти гида на Фукуоке можно несколькими способами:

## Инструменты для работы с PDF

Для конвертации PDF в структурированный формат можно использовать:

1. **Google Docs** → Export → Markdown (если есть расширение)
2. **pandoc** (через терминал): `pandoc file.pdf -o file.md`
3. **Code node в n8n** с библиотекой `pdf-parse` (нужно установить через npm)

Но лучше структурировать информацию вручную в Google Docs, разбив на секции по темам.
