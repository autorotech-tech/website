# Анализ workflow: Почему не выдаются контакты

## Структура workflow

1. **Webhook** → **Normalize From Site** → **Extract Message Data**
2. **Detect Language** → **Merge** → **Process & Combine Data** → **Filter Chat Action Output**
3. **Filter Chat Action Output** → **Multilingual AI Agent**
4. **Answer questions with a vector store** (tool) → **Multilingual AI Agent**
5. **Multilingual AI Agent** → **Normalize Agent JSON** → **Format Links for Web** → **Build Response** → **Respond to Webhook**

## Потенциальные проблемы

### 1. Контакты из метаданных БЗ не передаются в агент

**Проблема**: Узел "Answer questions with a vector store" находит документы с метаданными (контакты), но эти метаданные могут не попадать в контекст, который видит агент.

**Проверка**: 
- В description узла "Answer questions with a vector store" написано: "в метаданных есть контакты/ссылки и их нужно возвращать"
- Но агент видит только `content` документов, метаданные могут не передаваться

### 2. System Message не указывает на метаданные

**Проблема**: System Message говорит "Контакты: включай ТОЛЬКО из БЗ", но не указывает ГДЕ именно в БЗ искать контакты (в метаданных).

**Текущий System Message**:
```
"Контакты: включай ТОЛЬКО из БЗ. В контексте вопроса (VinWonders → контакты для билетов VinWonders)."
```

Агент может искать контакты в тексте документов, а не в метаданных.

### 3. Узел "Format Links for Web" правильно обрабатывает contacts

**Проверка кода**: Узел "Format Links for Web" корректно ожидает `item.json.contacts` и форматирует их. Это не проблема.

### 4. Узел "Normalize Agent JSON" правильно извлекает contacts

**Проверка кода**: Узел корректно парсит JSON и извлекает `data.contacts`. Это не проблема.

## Вероятная причина

**Контакты хранятся в метаданных документов в Supabase, но агент их не видит**, потому что:
1. Tool "Answer questions with a vector store" возвращает документы с метаданными
2. Но агент видит только `content` документов, метаданные не включены в контекст
3. System Message не указывает агенту искать контакты в метаданных

## Решения (без правок, только предложения)

### Вариант 1: Уточнить System Message
Добавить в System Message явное указание на метаданные:
```
"Контакты: ищи в метаданных документов БЗ (metadata.contacts). Если вопрос про «где купить/как связаться» — обязательно верни контакты из метаданных."
```

### Вариант 2: Проверить что метаданные передаются в контекст
Убедиться, что tool "Answer questions with a vector store" передает метаданные в контекст агента. Возможно нужен дополнительный узел для извлечения метаданных.

### Вариант 3: Проверить структуру данных в Supabase
Убедиться, что контакты действительно хранятся в метаданных документов в правильном формате:
```json
{
  "metadata": {
    "contacts": {
      "telegram": ["..."],
      "sites": ["..."],
      "phones": ["..."],
      "emails": ["..."]
    }
  }
}
```

2. **Посмотреть output узла "Multilingual AI Agent"** - видит ли агент метаданные в контексте?
3. **Проверить в Supabase** - как хранятся контакты в метаданных документов?

## Рекомендации

1. Сначала проверить output узлов в реальном выполнении
2. Если метаданные не передаются - добавить узел для извлечения метаданных
3. Если метаданные передаются - уточнить System Message для явного указания на метаданные
