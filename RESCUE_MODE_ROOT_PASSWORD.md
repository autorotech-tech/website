# Пароль root в Rescue Mode VNC

## 🔑 Важно понимать:

### Два разных пароля:

1. **VNC пароль** - для **подключения** к VNC консоли
   - Используется для доступа к VNC
   - Обычно в панели Contabo

2. **root пароль** - для **логина** в системе через VNC
   - Это пароль пользователя root
   - Нужен после подключения к VNC

## 🔍 В Rescue Mode:

### Если это чистая Rescue система (live CD):
- root пароль может быть **пустой** или стандартный
- Попробуйте просто нажать Enter (пустой пароль)
- Или стандартные: `root`, `rescue`, `admin`, `password`

### Если это chroot в основную систему:
- Нужен **реальный root пароль** вашего сервера
- Если пароль не был установлен (только SSH ключи), пароля нет

## 🔧 Решения:

### Вариант 1: Попробовать пустой пароль
Просто нажмите Enter после ввода `root`

### Вариант 2: Если пароль неизвестен - сбросить через Rescue Mode

Если вы уже в rescue mode и видите командную строку:

```bash
# 1. Проверить подключенные диски
lsblk
# или
fdisk -l

# 2. Примонтировать основной диск (обычно /dev/sda1 или /dev/vda1)
mount /dev/sda1 /mnt
# или для систем с LVM:
mount /dev/vg0/root /mnt

# 3. Примонтировать другие разделы если нужно
mount --bind /dev /mnt/dev
mount --bind /proc /mnt/proc
mount --bind /sys /mnt/sys

# 4. Chroot в систему
chroot /mnt

# 5. Сбросить пароль root
passwd root
# Ввести новый пароль дважды

# 6. Выйти из chroot
exit

# 7. Отмонтировать
umount /mnt/dev
umount /mnt/proc
umount /mnt/sys
umount /mnt

# 8. Перезагрузить сервер в обычном режиме
reboot
```

### Вариант 3: Если sudo пароль известен

Если у вас есть доступ через SSH к обычному пользователю vladx:

```bash
# Залогиниться как vladx
ssh -i ~/.ssh/id_ed25519_autoro vladx@46.250.228.229

# Установить пароль root
sudo passwd root
# Ввести sudo пароль (iddqdidkfa), затем новый root пароль
```

Но если сервер в rescue mode, SSH может быть недоступен.

## 📋 Определение типа Rescue Mode:

### Проверить, где вы находитесь:

```bash
# Проверить hostname
hostname

# Проверить файловую систему
ls -la /

# Если видите стандартную структуру (/etc, /home, /var) - это основная система
# Если видите rescue структуру - это live система
```

### Если это live rescue система:
- Обычно root пароль **пустой** или `root`
- Попробуйте просто Enter

### Если это основная система (chroot):
- Нужен реальный root пароль
- Если его нет - нужно сбросить через процедуру выше

## 🎯 Рекомендации:

1. **Сначала попробуйте пустой пароль** (просто Enter)

2. **Если не работает**, попробуйте стандартные пароли:
   - `root`
   - `rescue`
   - `admin`
   - `password`

3. **Если ничего не работает**:
   - Если можете выполнить команды (без логина), используйте процедуру сброса пароля выше
   - Или обратитесь в поддержку Contabo для помощи

## ⚠️ Важно:

- **sudo пароль (iddqdidkfa)** - это пароль пользователя vladx, НЕ root
- **root пароль** может быть не установлен, если использовались только SSH ключи
- В rescue mode можно сбросить пароль root без знания старого

## 🔐 После установки пароля root:

После того как установите пароль root, вы сможете:
- Логиниться через VNC как root
- Выполнять команды от имени root
- Сбросить пароли других пользователей
- Восстановить доступ к системе
