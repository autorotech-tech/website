# Настройка Core Tunnel для работы с autoro.tech

## Где добавить исключения в Core Tunnel

К сожалению, в стандартных настройках Core Tunnel (General, Connection, Advanced) **нет прямого места для добавления исключений доменов**.

Однако есть несколько способов решить проблему:

---

## Вариант 1: Использовать системные настройки macOS

### Настройка Proxy Exceptions в системных настройках:

1. Открой **Системные настройки** (System Preferences)
2. Перейди в **Сеть** (Network)
3. Выбери активное соединение → **Дополнительно** (Advanced)
4. Перейди в **Прокси** (Proxies)
5. Если используется SOCKS прокси (Core Tunnel), найдите настройки **Proxy Bypass** или **Ignore these hosts & domains**
6. Добавь:
   ```
   *.autoro.tech
   autoro.tech
   *.b-cdn.net
   *.kxcdn.net
   ```

**Но:** Это работает только если Core Tunnel использует системный SOCKS прокси.

---

## Вариант 2: Не использовать Core Tunnel для autoro.tech

### Вместо этого используй CDN домены напрямую:

1. **Не настраивай Core Tunnel для CDN доменов**
2. Используй CDN домены (например, `autoro-main.b-cdn.net`) без туннеля
3. Core Tunnel используй только для других сайтов

**Преимущество:** CDN домены обычно не блокируются провайдерами, поэтому туннель не нужен.

---

## Вариант 3: Настройка через конфигурационный файл Core Tunnel

Core Tunnel может использовать конфигурационный файл SSH. Попробуй:

1. Создай файл `~/.ssh/config` (если его нет)
2. Добавь настройки для autoro.tech:

```ssh-config
# Прямое соединение для autoro.tech (без прокси)
Host autoro.tech *.autoro.tech
    ProxyCommand none
    
# Остальные хосты через Core Tunnel
Host *
    ProxyCommand /path/to/core-tunnel -S %h:%p
```

Но это для SSH, не для веб-браузера.

---

## Рекомендуемое решение: Использовать CDN без Core Tunnel

**Самое простое решение:**

1. ✅ Настрой Bunny CDN (см. `COMPLETE_BYPASS_SOLUTION.md`)
2. ✅ Используй CDN домен (`autoro-main.b-cdn.net`) **БЕЗ Core Tunnel**
3. ✅ Core Tunnel используй только для других сайтов, которые действительно нуждаются в туннеле

**Почему это работает:**
- CDN домены (`*.b-cdn.net`, `*.kxcdn.net`) обычно **не блокируются** провайдерами
- Они выглядят как обычные CDN сервисы
- Запросы идут через стандартный HTTPS (порт 443)
- Не требуют VPN или туннеля

---

## Проверка

После настройки CDN:

1. **Отключи Core Tunnel** (или добавь исключение если возможно)
2. Попробуй открыть: `https://autoro-main.b-cdn.net`
3. Если открывается - значит CDN работает без туннеля!
4. Настрой фронтенд использовать CDN домен

---

## Итог

**Не нужно добавлять `*.autoro.tech` в исключения Core Tunnel.**

Вместо этого:
1. Настрой CDN (Bunny CDN или KeyCDN)
2. Используй CDN домен вместо autoro.tech
3. Работай без Core Tunnel для CDN доменов

Это решение будет работать даже в регионах, где блокируется Cloudflare, VPN и WireGuard.
